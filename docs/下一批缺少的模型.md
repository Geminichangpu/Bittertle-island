# 下一批素材缺项（2026-11-05）

适用项目：本地 `work/abo-island-local-test` 测试版。以下指本轮在 ABO 和新增 CC0 素材中仍未找到合适替代的内容，不代表原场景没有这些程序化构件。办公室桌子继续保留原模型。

## 优先找这些

| 内容 | 需要的模型 | 用途及当前缺口 |
|---|---|---|
| 云 | 5–8 种独立的柔软云团、长条云、大小云组 | 室内窗外仍是原程序化云；两批新素材均没有云模型。避免棉球硬拼、方块云、重体积特效。 |
| 开花盆栽 | 绣球、山茶、杜鹃、小雏菊等完整盆栽；也可找独立花簇 | 现有模型可以替换绿植与枝叶，但没有合适的完整开花植株。陶盆、花槽可复用。 |
| 花坛与灌木 | 无花盆的花簇、低矮灌木、蕨类、草丛，各 3–5 种 | 替换别墅花坛、园林、道路边的原球状花草。盆栽的阔叶只能覆盖部分用途。 |
| 海岸与林地植被 | 海岸草、芦苇、低矮海岸灌木、竹丛；需要时补樱花枝叶 | 新增素材只有树桩、倒木、苔藓、蘑菇，没有成套海岸和日式庭院植被。 |

## 素材规格

- 首选 GLB，带完整贴图；Y 轴向上，底部落在地面，尺寸接近真实米制。
- 柔和、低饱和，低面数或轻写实均可；避免过强金属反射、写实程度与小岛差距太大的高模。
- 小道具尽量几百至数千三角形；复杂单株或大型道具尽量控制在约 1–2 万三角形以内。贴图通常 1K 足够，植被尽量使用透明裁切而非多层半透明。
- 保留来源和许可文件；CC0 或明确可商用、允许修改及再分发的许可更便于集成。

## 与缺素材不同的工作

图书馆、学堂、餐厅、商铺、普通民居等还没有像办公室、卧室、神社住居、绯华楼、琉璃塔那样的独立室内入口及房间。部分家具已经有模型，但要开放这些室内，还需要另做房间布局、门窗、照明、交互与通行空间；找家具模型本身不能自动完成这一部分。
