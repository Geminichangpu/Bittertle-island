# Island nature and books

These cloud, shrub and book GLB variants were created for this project with Blender MCP. They do not contain third-party model assets.

- Three cloud variants, approximately 1,444 triangles each.
- Three shrub variants, approximately 600 triangles each.
- Three book variants, 72–84 triangles each.

The runtime selects variants deterministically to keep each location stable across reloads. The source modelling script is retained in `reports/abo-review/create-cloud-shrub.py`; the final exports also include subsequent shape refinements made in Blender.
