# 外景精修与绯华楼建筑群漫步 · 2026-10-26

本轮通过 Blender MCP 制作并保存模型，接入原项目。按用户要求不运行测试、类型检查、浏览器漫游、截图或渲染验证；本地打包仅更新启动文件。

## 既有精修的处理

树屋、绯华楼建筑群已有外景 Blender 母版，本轮不重复制作。基地卧室、办公室、神社住居以及其他区域已有室内精修，本轮全部沿用。

基地和神社建筑群的外景已有程序化瓦作、门窗与构件，但此前没有达到树屋、绯华楼这一轮的 Blender 分件精修层级。因此补充其外景细节和图片材质，不修改其室内模型。

## 文件与材质

- 可编辑总母版：`art_source/blender/exterior-set-v1/island-exteriors-refined-v1.blend`。
- 母版场景：`Island_Exteriors_v1`；每个对象独立 `EX_<对象 ID>` 集合，内部按木构、瓦作、门窗和装饰分件。
- 操作前 Blender 会话副本：同目录 `session-before-exteriors.blend`。
- 网页原件与变换：`source-meshes.json`、`source-manifest.json`。
- 各对象制作记录：同目录 `<对象 ID>-authoring.json`。
- 网页模型：`src/assets/models/<对象 ID>-exterior-refined-v1.glb`，共 16 个对象。
- 建模脚本：`D:/3D模型/scripts/refine_web_exterior_set_v1.py`。
- 生产贴图压缩：`D:/3D模型/scripts/package_exterior_textures.py`。

木纹、和纸、织物、石材沿用已经下载的 CC0 图片，来源与授权保存在 `assets/textures/indoor-common/manifest.json` 和 `assets/textures/shrine-residence/manifest.json`。Blender 保留完整图片及 UV；网页导出使用 512px JPEG 颜色、粗糙度和法线图片，以减小全岛外景同时加载的成本。网页压缩不改动可编辑母版和原始下载文件。

## 绯华楼建筑群漫步

在“室内 / 建筑群漫游”中选择“绯华楼建筑群 · 整体漫游”。进入点设在悬桥外端，沿桥抵达共同高台，可到主楼门前、副楼和温泉庭院外侧。导航栏提供各地点快捷移动。

主楼门前使用原有室内入口，进入室内后返回可继续建筑群漫游。沿用 WASD、鼠标观察、Shift、E 和触屏方向按钮，不添加持续播放动画。

碰撞从现有程序化分件生成，使用对象当前世界变换，避免把精修版按材质合并后的大包围盒当成墙。高台／悬桥的初始落脚优先使用指定表面高度，地面与栏杆仍参与碰撞；不通过降低地形或增加隐形大地板掩盖高差。

没有修改岛屿存档布局、部署 GitHub，或进行运行和视觉验收。
