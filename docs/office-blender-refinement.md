# 基地办公室 Blender MCP 分件精修 v1

依据用户提供的白天办公室参考图制作，物件形状分析见 [office-reference-analysis.md](office-reference-analysis.md)。本轮实际通过 Blender MCP 在 Blender 5.2.3 LTS 中创建、保存、导出模型。

## 制作内容

- 中央书桌：厚桌面、下沿、框板、榫钉、方脚、独立抽屉和弧形金属拉手。
- 木椅：略外撇椅腿、横撑、座面、三根靠背竖条和有弧度的宽顶板。
- 后墙组合柜：四格独立背板和层板、竖框、通长台面与顶板、下柜门板及铰链；第三格留出参考图中的工作台膝部空间和画板陈列位置。
- 文件夹和书册：独立封皮、纸页、书脊、标签、指孔金属环；混合直立、略倾斜和平放，层格留出间隙。
- 收纳盒：灰色、深蓝色和牛皮纸色盒体，带独立盒盖、标签框及把手。
- 桌上图纸：叠纸、轻微翘起的纸角和简化小岛规划线；另有六角铅笔。
- 花束与绿植：厚口陶盆、托碟、土面、枝条、尖叶、分瓣粉色小花和花心。
- 画板与文具：斜靠木框画板、纸夹、笔筒、带笔尖的铅笔、空心杯、杯把、茶水面及茶碟。
- 绿色窗帘：连续布面、束腰、纵向褶皱、折边、布带、系绳和上端挂环。
- 图片外区域沿用木作风格，补软木便笺板、入口合页和螺丝；保留原有地板、门窗、木墙和天花结构。

## 可编辑文件

- `art_source/blender/office-v1/office-refined-v1.blend`：母版；`Office_Interior_v1` 场景包含分件的 `Office_Refined_v1` 集合。
- `Office_Original_Archive`：隐藏的原室内网格归档。
- 同目录 `session-before-office.blend`：操作前 Blender 会话副本。
- 同目录 `source-meshes.json`、`source-manifest.json`、`office-original.glb`：现有生成器导出的源数据和原件。
- 同目录 `textures/`：本轮木纹和布纹贴图；贴图和参考图片已打包进母版，参考图片不进入网页 GLB。
- `src/assets/models/office-interior-refined-v1.glb`：网页精修资产。

各柜格、文件夹、抽屉、椅子结构、窗帘和摆件按独立集合组织；网页导出只在部件与材质相同的范围内合并，不压平母版。

制作入口为工程内 `scripts/export-office-source.mjs`、`scripts/export-office-source-entry.ts`，以及 `D:/3D模型/scripts/refine_web_office_v1.py`、`D:/3D模型/scripts/export_web_office_v1.py`。建模脚本复用卧室、树屋脚本中的纯构造函数，不执行它们的场景代码。再次制作应另存版本。

## 网页接入

基地办公室默认使用精修模型，底部提供“原版室内 / 精修室内”切换；加载失败保留原版，可重试。`?models=original` 沿用原版启动方式。

保持原房间尺寸、入口和相机配置，模型沿用房间根节点的缩放。按家具、墙壁和天花容器分别挂载，沿用剖面隐藏逻辑；原生格窗纸面继续使用昼夜材质。原碰撞配置继续用于漫游，未按新网格重建碰撞。切换时重新关联互动实例、恢复静音和环境灯态；加载和切换才请求绘制，不新增持续动画。

本轮仅制作、导出并本地打包启动文件；按用户要求，未运行测试、类型检查、浏览器、截图或渲染验证，网页接入效果尚未经运行验收。未部署 GitHub。
