日期：2026-11-05。基线 `eaaf318`；备份分支 `backup/before-abo-island-20261105`；独立测试分支 `work/abo-island-local-test`。原主项目代码未改动，未发布。

## 本轮实际使用范围

- CC0 新素材 33 种全部已配置使用；ABO 模型使用 32 种。各自来源保存在 `src/assets/cc0-test/ATTRIBUTION.md`、`SOURCES.json` 和 `src/assets/abo-test/ATTRIBUTION.md`，应用“第三方声明”也包含这些记录。
- 全岛外部 29 个对象，共 174 处模型；海滩 10 张躺椅；现有九处室内场景共 97 处模型。合计 281 处，包含新增陈设与替换件，不能把这个数字理解为 281 个原物体都被替换。
- 办公室原桌子保留。书柜、餐饮桌椅、餐车、柜架、篮筐、仓储、床、沙发、座椅、窗帘、地毯、灯具、盆栽和林地小物均有使用。
- 室内 43 株原有盆栽通过原始花盆实例提取位置，整株替换。民居和餐厅原有成排球状盆栽也替换；图书馆石花槽以及新花槽改用模型叶片，保留对应容器。
- 农田保留种植布局，新增收纳和工具棚货架，树桩、倒木和蘑菇放在田埂外。自然小物按实际地形落地。
- 餐厅原方桌与凳子、原公园长椅、原民居盆栽仅在替代件完整加载后隐藏。漫游的低成本碰撞代理也剔除这些已隐藏的旧件。
- 室内合并网格的替换限定在指定家具体积；建筑墙体、楼梯、玻璃等结构不参与裁切。花草使用更严格的三角形范围，避免裁掉邻近书本。旧家具碰撞在新件就位时清理。

## 验证范围

- TypeScript 检查及生产构建通过。
- 九处室内：办公室、卧室、神社住居、绯华楼、琉璃塔五层。检查资源加载、出生点、四向短距离行走、漫游切换和原办公室桌子可见性，并逐处截图。
- 263 个实体阻挡体（室外 166、海滩 10、室内 87）逐个检查中心阻挡与跨越扫掠防穿透。装饰性窗帘、地毯、高处吊灯及小蘑菇等明确不作为实体阻挡。
- 21 条规划道路中心通路抽样：新增物件未占用抽样中心通路。餐车及边桌上的陶罐、锅和台灯通过向下射线确认承托位置。
- 全岛漫游实际启动；旧替换件的隐藏状态检查；重点区域近景截图。

这些检查不等于遍历全岛每个角落、所有楼梯动作、所有设备和长期性能。家具整体包围盒会把椅子腿之间的小缝隙视为实体；建筑仍沿用原有门洞、桥面和楼梯碰撞代理。

结果在本机 `reports/abo-review/room-results.json`、`collision-results.json`、`exterior-assets-results.json`。截图为该目录下的 `final-*.png` 和 `complete-*.png`。

## 复查方法

在本测试目录运行 `npm run dev -- --port 4197 --strictPort` 后，依次运行：

```text
node scripts/check-island-asset-interiors.mjs
node scripts/check-island-asset-collisions.mjs
node scripts/check-island-asset-exteriors.mjs
```

使用本机 Chrome 和已有的 playwright-core。不要并行运行多个软件渲染浏览器验收。

查看成品：先运行 `npm run build`，再双击根目录 `启动ABO试放.cmd`，使用独立的 4185 端口。

## 仍缺的素材与边界

详细找素材清单见 `下一批缺少的模型.md`。最优先是云团、开花盆栽、花坛花簇、低矮灌木；其次是农具、食物及厨房设施、神社祭具、渔具与码头用品、配套日式公共设施和建筑细部。

新素材里没有场景云模型，也没有合适的完整开花植株；未把盆栽模型硬充作所有园林植物。旧的天空云、部分花坛及灌木、食品和专用场景道具仍使用原程序化构件。

本轮“室内”指现有可进入的九处场景。图书馆、学堂、餐厅、商铺、普通民居等的新独立室内仍需要另做空间、入口、交互和通行设计，并非缺一张家具模型就能自动开放。

`abo-selection.csv` 覆盖 7,953 个 ABO 编号，明确区分资料/结构筛选、商品图对照与实际加载；不能把自动筛选当作 7,953 个模型逐个进入小岛的视觉验收。
