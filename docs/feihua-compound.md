# 绯华楼山腰建筑群 · 2026-10-26

按用户最新纠正：温泉在副建筑后方；主楼、副楼和温泉是可分别选择的三个建筑对象，整体像神社与基地一样归入一个建筑群。共用高台位于山腰，前方以水平悬空木桥跨过山沟接入。

本轮仅制作并同步启动文件，未运行测试、类型检查、浏览器或截图验证。

## 对象结构与编辑

feihua_group（绯华楼建筑群）包含：

- landmark_feihua：主建筑，保留旧 ID 与全部现有室内关联。
- feihua_annex：副建筑，位于主楼左侧。
- feihua_onsen：温泉建筑与庭院，位于副楼后方。
- feihua_terrace：共用石砌高台。
- feihua_bridge：水平悬空木桥，桥下没有落地支撑柱。

编辑器左侧显示“绯华楼建筑群（整体）”，下方三个建筑和高台、桥均可单独选择、移动、旋转、缩放。整体移动仍使用同一个父组。

主楼与旧外观的 X/Z、朝向及整体尺度沿用；只在迁移时将建筑群抬到山腰，当前默认组原点高度为 12，若旧建筑已经更高则保留其高度。主楼局部位置归零，原有变换转移到父组。室内模型、房间布局及互动入口未修改。

## 地形与桥

- 新增持久化 terrain.feihua 山腰地形参数，真实地形采样和网格生成均使用它。
- 高台底部形成稳定的山腰台地，后方坡面继续抬高，前方保留暴露石墙和下落坡面。
- 木桥水平跨过山沟，两端分别接高台和独立坡地桥台；桥下地形降低，不使用倾斜台阶和落地柱。
- 远端坡地沿山路方向平缓下降，环境道路从桥的远端衔接。
- 删除旧绯华楼低平地基，不在整条桥下铺满会填平山沟的方形地基。整体编辑时山腰参数随共用高台更新。
- 只调整绯华楼周围的局部地形；海岸线和中央人工岛参数不变，其他建筑自身地基继续保留。

## 旧工程与存档

upgradeFeihua 在默认工程、JSON 导入和 IndexedDB 存档读取时执行一次分组迁移；已有 feihua_group 的工程不重复拆分或重置用户编辑。旧本地存档迁移前写入现有备份表。

根布局、示例工程和只读项目文件已写入新结构；修改前副本在 reports/feihua-hillside/before/。历史示例不批量改写，导入时按相同规则迁移。
