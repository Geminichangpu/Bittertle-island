# 基地卧室参考分析与 Blender 分件方案

参考：`D:/比特尔特/2-美术/2-背景图片/01_角色线/01_序章/序章_岛上卧室室内关门_白天.png`。

## 图片中可见的形状与材质

| 物件 | 外形、结构与表面 | 制作处理 |
| --- | --- | --- |
| 木床 | 低平台、四个方腿、薄侧梁，床头为宽横板，边缘磨圆 | 床脚、梁、床头板分别制作，保留现有床位 |
| 床垫 | 厚圆角长方体，软包侧边有弧度 | 独立软包网格，周圈缝线和轻微压陷 |
| 床单/被面 | 米白大面，顶部平缓，侧面自然垂落，床角有斜褶 | 连续布面，床边垂坠、脚端褶皱和折边，不用硬盒代替 |
| 双枕 | 两个蓬松扁枕，中心鼓起、四角收束，枕边有细缝 | 独立左右枕，各自带不同的小褶与滚边 |
| 床侧矮书架 | 三层开口、厚侧板、较暗后板、顶部平盖 | 三层独立搁板，书本直放/轻倾/平叠，保留原床边位置 |
| 墙边高书架 | 嵌入式竖直框架、深色内部、木层板；下方有抽屉 | 高书架、抽屉和把手分件，层板摆书、相框与绿植 |
| 书桌 | 直线木桌，较厚桌面，桌下留腿部空间 | 保留书桌位置，开放膝部空间，补抽屉、榫钉及收纳盒 |
| 木椅 | 方腿略外撇、木坐板、宽圆角靠背、细直立支柱 | 座面微凹，靠背微曲，脚撑与圆角独立处理 |
| 房门 | 竖板木门、矩形门套、两只金属合页、银灰横把手 | 保留现有开门角与出口位置，精修板缝、门套、合页和把手 |
| 大窗 | 厚木框、上部横亮窗、下部竖分格，银色长把手 | 保留透光玻璃，增加压条、接缝、金属底座和螺丝 |
| 白窗帘 | 顶部密褶、下部展开，在偏低处束紧，底边柔软 | 左右独立曲面，布褶、束带、折边和吊环分件 |
| 书与文件夹 | 蓝绿、米色、棕红书脊，厚薄不一，标签和装订孔 | 不规则但整齐的分组，纸页块、封皮、书脊和标签分别建模 |
| 小摆件 | 方形照片框、白/灰陶盆、细叶绿植、笔筒和纸盒 | 陶盆带厚口与土面，相框有画芯，文具和纸张保持适量 |
| 地板与墙 | 暖灰褐木色；竖向墙板、错缝长地板，深色框梁 | 保留房间轮廓，以木纹、拼接和小倒角细化，避免过度粗糙 |

图片之外的补全：现有后角矮柜采用同色框板与四只抽屉；藤编收纳篮配白色内衬；素色小地毯补包边；吊灯保留原位置和互动功能，外观延续朴素木框暖光。

不把画中阳光斜影烘焙成固定污渍；网页继续用原昼夜光照。房间比例、反 L 轮廓、相机视角和室外建筑位置沿用。分件母版与网页导出副本分别保存。
