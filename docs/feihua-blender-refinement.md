# 绯华楼建筑群 Blender 外观精修 v1

2026-10-26，通过已连接的 Blender MCP 在 Blender 5.2.3 LTS 中制作。遵照本次指示，未运行类型检查、测试、截图、浏览器检查或渲染验收；只进行源网格提取、建模、保存、导出与本地网页打包。

## 外观制作

- 主楼：保留三层楼体与屋顶望楼，新增瓦当圈纹、屋脊卷饰、檐口嵌线、木柱榫钉、窗台、栏杆金属箍、入口花纹徽饰；外侧灯笼改为圆润纸壳和环形骨架，紫色门帘改为褶皱网格。
- 副楼：保持独立双山墙，增加瓦当、山墙花饰、窗台、廊柱斜撑、柱脚箍与木廊钉头。
- 副楼后方温泉：保留独立庭院与浴舍，细化矿物色池面和静态水纹、池石苔缝、竹叶与篱笆绑绳、蓝色布帘褶皱及温泉刺绣、木桶箍和浴勺。
- 高台与悬桥：细化压顶石拼缝、墙脚苔色、花槽角铁、桥板木纹与螺栓、悬索夹具和端部柱脚。桥仍水平悬空。

室内文件、入口逻辑、建筑群位置及地形参数均沿用。三个建筑和两个场地部件继续使用各自的原有对象 ID、父组和变换。源网格直接来自现有生成器；Blender 中只对指定外侧灯笼、门帘和温泉池面进行替换，其余原网格保留并增加外观细节。

## 可编辑源文件

`art_source/blender/feihua-v1/feihua-refined-v1.blend`

- 独立场景 `Feihua_Exterior_v1`。
- `Feihua_Refined_v1` 集合下有五个独立根节点，子网格按建筑细节和材质组织。
- 隐藏集合 `Feihua_Original_Archive` 保留原网格；先前灯塔和其他 Blender 场景继续保留。
- 中文招牌使用可编辑文字，字体打包进母版；只在网页导出副本中转换网格。
- 操作前会话副本：同目录 `session-before-feihua.blend`。
- 原始数据：`source-meshes.json`、`source-manifest.json` 和五个 `*-original.glb`。原始网格 GLB 的招牌底板不含网页 Canvas 字样；网页原版仍由生成器完整绘制文字。

制作脚本：`D:/3D模型/scripts/refine_web_feihua_v1.py`。导出脚本：`D:/3D模型/scripts/export_web_feihua_v1.py`。网格提取：工程内 `scripts/export-feihua-source.mjs`。制作脚本不覆盖已有同名精修场景，后续版本应使用新的场景和输出名称。

## 网页回接

`src/assets/models/` 下五个 `*-refined-v1.glb` 对应主楼、副楼、温泉、高台与悬桥。每个文件为对象局部坐标，导出前仅将副本按材质合并；保留母版的可编辑分件。

`src/models/FeihuaRefinement.ts` 默认启用精修外观，在已有根节点下替换可见子网格。编辑器和只读网页增加“绯华楼外观”的原版/精修切换，独立于灯塔。`?models=original` 可让两组都显示原版。模型加载失败时保留原版，可重试。

尺寸与颜色参数匹配本次来源时应用精修模型；参数被编辑后该部件回退到程序化生成器，以免覆盖新参数。位置、旋转、缩放和父组变换继续生效。灯笼与窗户保留昼夜发光角色，无持续渲染动画。

本轮运行 `node scripts/package-local.mjs` 更新编辑器、只读启动文件和分享模板；没有部署 GitHub，也没有执行验证。
