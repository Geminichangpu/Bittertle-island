- Three.js 保持 0.187.0 和 WebGLRenderer。建筑、根布局、道路路线、可行走地形、交互、精模距离阈值、DPR 上限、按需绘制和阴影缓存保留。

完整实现文件与同镜头记录见 [自然环境报告](nature-sample-report.md)。最终无标签图及 JSON 在本地 `reports/nature-sample/`，不提交 PNG 或构建产物。`after.json` 是最终五镜头结果；`meadow-after-meadow.png` 是红框补树近景。
