# 比特尔特岛：与她们共度的日常

一段发生在宁静海岛上的恋爱与日常故事。

因为一次人生转折，你离开熟悉的生活，来到远离城市的比特尔特岛。在这里，你会遇见性格各异的女孩，与岛民们相识，慢慢融入小岛的生活。日常的对话和选择会逐渐改变彼此的关系，让看似平凡的时光成为珍贵的回忆。

## 游戏特色

- **恋爱与日常故事**：在相处中了解角色，逐渐发展感情，体验属于彼此的故事。
- **岛民的支线故事**：探索小岛，倾听居民们各自的经历与心事。
- **小岛生活**：体验会员、商店和每日抽签等内容；后续计划加入种田、钓鱼等休闲活动。
- **特别的生日**：游戏中的角色与你的生日都可能带来特别的互动。
- **故事中的故事**：在小岛日常之外，还有一个剑与魔法世界的故事等待探索。
