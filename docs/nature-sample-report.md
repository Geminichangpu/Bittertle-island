# 自然环境样板：本地验收记录（2026-11-03）

本轮包含自然环境样板、坡道石阶、西峰渐变和东岸草坡补树。实现基线 `c57ac2642923f016c060bff7949811e74b9591af`，开始时没有未提交修改。本地构建已更新，可继续使用原启动脚本。最终发布检查和旧模块清理见 [发布记录](publish-nature-20261103.md)。

## 效果与范围

- 以神社东岸为样板，包含草坡、树林、临海山崖和海面。主地表在该区域混合草、裸土/碎石和陡坡岩石的底色、法线、粗糙度；用真实道路和树根位置生成过渡场。远处淡化细法线，混合旋转与不同尺度的草地纹理，降低重复感。
- 样板使用独立固定种子，保留疏密林带和入口空地。最终 70 棵树分为高窄 13、宽冠 17、偏斜 16、棕榈 12、露兜树形 12；其中东岸草坡在原先 58 棵的基础上补入 12 棵，原有树木不挪位。叶片、树干继续实例化，使用不透明折面叶片，无新增树木贴图、GLB 或动画循环。105 个近景小草簇实例按镜头距离显示。
- 自然岩岸只调整固定崖顶下方的装饰几何，加入凹凸、斜坡和 64 块分组实例化坡脚岩石；三平面采样减少竖壁纹理拉伸。人工岛挡土墙、原沿崖碎石步道保留。没有修改可行走地形、桥头高度或建筑地基。
- 256×256 岸线距离图覆盖主岛和内岛，静态深浅水跟随真实海岸，低岸使用窄湿沙带和不均匀弱泡沫。移除旧的矩形海浪条；没有实时反射或额外深度通道。微动仍受原开关、近景、页面可见性及减少动态效果偏好控制。
- 坡道不再按隔行白色条纹着色，改为连续石铺路底；样板陡坡增加 27 级有侧面的完整石踏步，合并为一个网格。几何限定在现有路幅内，行走碰撞仍使用原坡道。

引擎仍是实际安装的 Three.js 0.187.0 和 WebGLRenderer；本轮没有再升级引擎或迁移 WebGPU。建筑模型、位置、道路路线数据、交互、精模加载阈值、全局 DPR 上限及阴影策略未改。`RefinementManager` 的唯一修改是在挂载海崖精模时隐藏被新植被替换的旧树组件，避免重复树冠。其他区域没有推广新的高精度树林或地表层。

## 绘制测量

本机 Chrome、ANGLE / NVIDIA GeForce RTX 2060 SUPER / Direct3D11。每镜头等待加载完成后预热三次，再执行十次 `renderNow()` + `gl.finish()`，记录中位数。它包含 CPU 提交与等待 GPU 完成，不等于实际帧率，也没有测持续平移时的 FPS。

| 镜头 | 绘制调用 前→后 | 三角形 前→后 | 中位耗时 前→后 |
|---|---:|---:|---:|
| 全岛 | 649 → 655 | 2,107,319 → 2,004,544 | 5.20 → 4.20 ms |
| 完整样板 | 338 → 345 | 1,860,410 → 1,766,035 | 1.90 → 2.30 ms |
| 树林近景 | 259 → 267 | 1,519,862 → 1,441,695 | 2.10 → 1.50 ms |

*阶梯这组期间也加入了热带树形，因此调用和三角形差值包含树形变化，不能全部归因于踏步。只比较同镜头最终结果。各镜头静止一秒额外帧均为 0。短样本存在着色器缓存、驱动状态和计时噪声，不据此宣称帧率提升。

现有诊断按纹理面积和 mipmap 估算的全岛纹理占用从 141.19 MiB 到 157.19 MiB（约 +16 MiB），几何缓冲估算从 13.36 MiB 到 14.41 MiB。这不是实测显存，未完整统计阴影、材质 uniform 里的纹理及驱动开销。近景精模原本就会占用更多内存，本轮未取消按距离加载与退出。

## 加载速度

同一个本地 HTTP 发布服务、1280×800、DPR 1、禁用浏览器缓存；服务器未启用压缩和 CDN。各条件各跑一次。`firstDrawMs` 实际判断画布和加载界面就绪，不能当作浏览器 FCP/LCP 或所有纹理完成时间。“全岛完成”包含最后一次网络活动后两秒等待。

| 条件 | 画布就绪 前→后 | 全岛资源完成与静默 前→后 | 靠近神社后下载与静默 前→后 |
|---|---:|---:|---:|
| 本机无限速 | 13.75 → 10.89 s | 15.56 → 12.70 s | 7.15 → 3.64 s |
| 10 Mbps、80 ms 延迟、4 倍 CPU 降速 | 40.47 → 39.83 s | 48.70 → 49.06 s | 53.83 → 53.34 s |

首次全岛资源体积 10,124,592 → 11,385,086 字节（+1,260,494 字节，约 1.20 MiB），请求 25 → 28。新增首次请求主要是已有但原来未在启动阶段使用的三张 `coast-ground` 贴图：433,286 + 481,545 + 324,238 = 1,239,069 字节，约 1.18 MiB；其余约 21 KB 是代码增量。树形本身没有新增图片下载。

两版默认全岛均为 0 个精模请求；靠近神社后的新增资源均为 63,542,511 字节，包含神社和相邻建筑，共 12 个模型，下载最多并发 2。较大的既有精模下载仍然存在，未在本轮重新压缩建筑。无限速测量受系统/驱动缓存及调度影响，不能把时间缩短解释为代码优化；限速一轮的总就绪时间基本持平。浏览器网络/CPU 限速不模拟低端 GPU。

## 已检查与限制

- TypeScript 检查、viewer 构建、编辑器构建及 `git diff --check` 通过。构建保留第三方 Zod 的注释注解警告；最终编辑器应用块约 759.24 KB，触发现有 750 KB 提示。没有因此扩大本轮为代码拆包任务。
- 浏览器场景和生产加载检查的控制台错误、警告、失败请求、HTTP 错误均为 0。默认全岛不驻留精模，近景会加载，返回全岛后精模卸载、小草簇隐藏。
- 实际主地形 position、normal、color、index 与原地形函数的结果完全一致。70 个树根与三角网格的高度误差为 0；最小树间距 3.817 米，道路中心线最小净距 6.284 米；新环境属性无 NaN/Infinity。装饰岩岸和踏步不改行走碰撞。
- 最终复测水面微动开启时一秒请求 19 帧、阴影刷新 0 次；关闭后静止额外帧 0。轻微镜头移动不刷新静态阴影。256² 水面距离场覆盖主岛与内岛，抽样量化误差不超过 0.126 米；这是网格中心量化误差，沿岸插值仍受约 2–3 米单元尺寸限制。
- 神社建筑群可进入/返回，6 个漫游地点、5164 个碰撞盒可用；3 个摇铃部件可以触发动画。检查用于发现接入问题，不代表验收岛上所有交互。
- 未验证：其他显卡、手机、Safari/Firefox、实际 GitHub/CDN 网络、长时间连续漫游帧率及全岛每一处海岸。未做复杂回归或旧版兼容检查。样板视觉仍需用户本地验收，再决定是否推广。
